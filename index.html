Featured Projects

Emirates Robotics Competition (ERC) 2026

Autonomous Library Assistant Robot

Developed a comprehensive ROS 2 software stack for a TIAGo Pro mobile manipulator at the Mohammed Bin Rashid Library. Configured ROS 2 Humble & Gazebo Harmonic in Docker, customizing Mesa drivers and Vulkan OpenGL overrides for stable GPU acceleration. Programmed the robot's omnidirectional mecanum base to navigate toward a 5.25m shelf unit, utilizing a custom trigonometric LiDAR line-fitting algorithm to mathematically prove shelf flatness and parallel-park smoothly. Built a continuous 3D perception node processing RGB-D camera feeds & PointCloud2 data with a dynamic speed-decaying state machine. Engineered a collision-free grasping pipeline with MoveIt 2 and OctoMap scene planning for the 7-DOF arm to extract books and deposit them into collection bins.

  • ROS 2 Humble
  • TIAGo Pro Manipulator
  • MoveIt 2 & OctoMap
  • Gazebo Harmonic
  • LiDAR Line-Fitting
  • PointCloud2 Vision
  • Docker GPU Acceleration

Integrated WiFi connectivity with ThingSpeak IoT cloud telemetry and custom web app computing Heat Index, Dew Point, and Hazard Scores in real-time.
