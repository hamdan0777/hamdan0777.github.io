## 🌐 Step-by-Step: Host on GitHub Pages (Free)

### Step 1: Create a GitHub Repository
1. Log into your [GitHub account](https://github.com).
2. Click the **+** icon in the top right $\rightarrow$ **New repository**.
3. Choose a repository name:
   - For user site: `<your-github-username>.github.io` (e.g. `mohammed-hamdan.github.io`)
   - Or generic name: `portfolio`
4. Set visibility to **Public**.
5. Leave **"Add a README file"** **unchecked**.
6. Click **Create repository**.

---

### Step 2: Push Your Code
Open PowerShell or your command prompt in this directory:
`C:\Users\moham\.gemini\antigravity\scratch\portfolio`

Run the following:

```powershell
# 1. Stage and commit your changes
git add .
git commit -m "Tailor portfolio to Mohammed Hamdan Ruknuddin details"

# 2. Link your GitHub repository (replace <your-username> and <your-repo>)
git remote add origin https://github.com/<your-username>/<your-repo-name>.git

# 3. Push to main branch
git push -u origin main
```

*(If you ever update the site in the future, just run `git add .`, `git commit -m "Update"`, and `git push`!)*

---

### Step 3: Turn on GitHub Pages
1. On GitHub, navigate to your repository.
2. Click **Settings** (top tab) $\rightarrow$ **Pages** (in the left sidebar under *Code and automation*).
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` and folder `/ (root)`.
4. Click **Save**.
5. Your portfolio will be live in 30–60 seconds at `https://<your-username>.github.io/`!
